# cozy-skin

Cozy colour presets, table copy and export buttons, and spinner words for Claude Code.

**Windows only for now.** Built and tested with Claude Code 2.1.299 on Windows 11, in the terminal and the desktop app. Several parts call Windows itself: `/cozy auto` reads the Windows light or dark setting, the CSV and XLSX exports use the Windows Save dialog and PowerShell, the times on older prompts are read by a PowerShell script, and `/cozy terminal install` writes Windows Terminal schemes. On macOS or Linux the presets and tables still draw, but those parts do not work.

## What it does

- Ten presets, each with a light and a dark mode. Three are e-reader looks: `kindle`, `sepia` and `paper`. Six follow popular VS Code themes: `solarized`, `gruvbox`, `nord`, `dracula`, `catppuccin` and `tokyo-night` (see NOTICE). Their colours are the themes' own, moved just far enough to reach 4.5:1 where a colour is used as text. `contrast` (High contrast) is cozy-skin's own, with every text colour at 7:1 (WCAG AAA) for long sessions or bright rooms. A preset colours your prompt bubble, inline code in Claude's replies, the tables cozy-skin draws, the dots on tool rows and the Windows Terminal scheme, all at once; a colour you pick for your text or for inline code takes over from it. The spinner and the turn footer say the preset's words but keep the engine's colour.
- Tables get Copy, CSV and XLSX buttons. Copy and the exports use the exact cell text, not the drawn text. CSV and XLSX ask first where the file goes: the project's `cozy-exports` folder, a place picked in the Windows Save dialog, or a folder or file path typed under Other. The Save dialog opens above every window and takes a few seconds to start; the table says so meanwhile. After a save somewhere other than the project, the next question offers that folder too, and the Save dialog opens in it.
- A table longer than 20 rows shows its first 10 and a Show all button (Show fewer folds it again); Copy and the exports always take every row.
- XLSX files have a bold header on a grey band that stays in view while you scroll, filter buttons on it, and figures such as $12,400, 1,200 and 12.5% stored as numbers with a format that shows the same text. A typed file path is never written over an existing file.
- On the desktop a table is a framed grid as wide as the reply, in the preset's colours on its paper: a header band, a stripe on every other row, and columns of figures right-aligned. Columns share the width by their content, never narrower than their longest word, and a long cell wraps inside its column, so the grid always fits and no column is cut off. A table of more than five columns shows its first column pinned and four others at a time, with ◀ ▶ under it to step through the rest (Claude Code gives mods no sideways scrolling, so this stands in for one). On the terminal the same happens when the columns would have to break their words to fit the window. Words and inline code are moved just far enough to read at 4.5:1 on each band. Under it, the row and column count sits left of the buttons. The panel's Tables switch turns all of this on or off.
- The spinner and the turn footer use the preset's own words.
- `/cozy` switches the preset and mode. The command is `/cozy` because Claude Code has a built-in `/theme`.
- Claude Code's own theme is left alone until you run `/cozy <preset>`, `/cozy light`, `/cozy dark` or `/cozy auto`. From then on it moves with the skin. The package ships a Claude Code theme file for every preset and mode (`cozy-<preset>-light` and `cozy-<preset>-dark`) in `themes/`. When Claude Code lists them, `/cozy` picks them. Otherwise it falls back to the built-in `light` or `dark`. If you pick another theme by hand later, cozy-skin leaves it alone at the next session start. `/cozy off` puts your previous theme back.

## Install

In a Claude Code terminal session, type:

```
/plugin install cozy-skin --marketplace Synthesizzz/cozy-skin
```

Answer `y` to add the marketplace, then pick a scope (user scope puts it in every project). Then run `/cozy panel` to pick a look.

Run `/cozy off` before uninstalling, to put your Claude Code theme back.

## Developing

`npm install`, then `npm run check` type-checks, validates and runs the tests (`claude plugin test .`). To run your working copy, start Claude Code with `claude --plugin-dir <this folder>`. `.claude-plugin/types/` is generated by Claude Code for type checking and is not committed.

## /cozy

- `/cozy`: show the current preset, mode and settings
- `/cozy <preset>`: `kindle`, `sepia`, `paper`, `solarized`, `gruvbox`, `nord`, `dracula`, `catppuccin` or `tokyo-night`
- `/cozy light`, `/cozy dark`: fix the mode
- `/cozy auto`: follow the Windows light or dark setting
- `/cozy off`: turn the skin off and restore your Claude Code theme
- `/cozy on`: turn the skin back on with the settings it had
- `/cozy calm on|off`: keep one spinner word for the whole turn
- `/cozy icons unicode|ascii`: glyphs or plain ASCII in buttons and table borders
- `/cozy bubble cozy|app`: who draws your prompt on the desktop. `cozy` (the default) is a bubble on the preset's paper with its time, Copy and Edit on hover. `app` is Claude Code's own bubble, in the app's colours, with what only it has: Rewind, Fork, selecting its text and its right-click menu. The terminal's prompt line is cozy's either way. Also in the `/cozy` panel.
- `/cozy tools on|off`: a dot in the preset's colour beside each tool call (reading, writing, running, searching, the web, MCP; muted for the rest, red when a call failed, hollow while it runs). The row itself stays Claude Code's own; in the terminal a folded group gets one dot for each kind in it. The desktop draws a folded group's line ("Ran 2 commands") as a block nothing can sit beside, so there it stays as Claude Code draws it.
- `/cozy tables box|text|off`: boxed tables (the grid on the desktop), plain aligned text, or leave tables alone. In a narrow terminal the box stays: columns give way, widest first, and long cells wrap inside them; only a window too narrow for three cells a column gets plain text.
- `/cozy save <name>`, `/cozy look <name>`, `/cozy forget <name>`: keep the preset, mode and colours you have now under a name (lowercase letters, digits and dashes, up to 12 looks), bring them back in one step, or drop one. Saved looks are buttons under Your looks in the panel.
- `/cozy panel`: open a panel to turn the skin on or off and click the preset, the mode, your text colour and the inline code colour. A row of dots shows the preset's palette and your picks.
- `/cozy color code <name>|#rrggbb|off`: the colour of inline code (like `this`) in Claude's replies, on a faint grey chip. It follows the preset's accent until you pick one; `off` goes back to the preset. cozy redraws only the paragraphs, list items and headings that hold inline code; the rest of the reply (links, code blocks, quotes) stays Claude Code's own. In a redrawn line a web link stays a link you can press; another target (a path) shows its address beside it.
- `/cozy color you <name>|#rrggbb`: the text colour of your own messages, in a bubble on the preset's paper on the desktop. Names are `ink`, `rust`, `plum`, `teal`, `slate`, `olive`, `brick` and `ochre`: each has a shade for light mode and one for dark mode, and follows the mode. A `#rrggbb` stays as typed. Until you pick one it is the preset's own ink; `off` goes back to that. A prompt sent with an image keeps Claude Code's own bubble, since only that one can show the picture (a mod cannot read the image or draw it in a bubble of its own): cozy notes which prompts carried images as they are sent (the last 200, kept across sessions). Hover the bubble for how long ago you sent it, Copy and Edit (Edit puts the prompt in the prompt box). The time is noted as each prompt is sent, and for prompts sent before that, read from the session's transcript when the session starts. Drawing the bubble replaces Claude Code's own, so its Rewind button is gone from it: a mod cannot rewind, so use `/rewind` or Esc twice. Its text cannot be selected either, and its right-click menu is only Copy and Select All: the desktop allows neither on a prompt row a mod draws. Claude's replies keep Claude Code's own look.
- `/cozy terminal install`: write the Windows Terminal colour schemes (see below)

`calm`, `icons`, `tables` and `terminal install` never change Claude Code's theme.

## Limits

- No window background in the Desktop App: a mod cannot paint the window.
- No fonts: a mod can set size, weight and monospace, not a typeface.
- The engine's own shimmer cannot be switched off. Calm mode covers what cozy-skin draws.
- The spinner keeps the engine's colour. Only its words change.
- In the terminal, table cells drop inline markdown marks when drawn (`**bold**` shows as `bold`, `[text](url)` as `text`). The desktop grid keeps bold, italics, links and code. Copy and the exports keep the exact cell text, marks included.
- A mod cannot write to the terminal, so the window colours do not change by themselves.

## Spinner and calm mode

The spinner and the turn footer use the active preset's words. Calm mode keeps one spinner word for the whole turn. The engine's own shimmer is not something the mod can switch off, so calm mode covers what cozy-skin draws. The spinner row keeps the engine's colour: no prop carries one, so the preset accent is not applied to it.

## Windows Terminal

A mod cannot paint the terminal window, so cozy-skin ships matching colour schemes for Windows Terminal, one per preset and mode, named like `cozy-nord-dark`.

Run `/cozy terminal install`. It writes one JSON fragment to `%LOCALAPPDATA%\Microsoft\Windows Terminal\Fragments\cozy-skin\cozy-skin.json` and nothing else: the fragment adds schemes only and never changes your profiles. Restart Windows Terminal, then pick a scheme under Settings, your profile, Appearance, Color scheme.

A mod cannot write to the terminal either, so it cannot switch the window colours for you. When you change preset or mode with `/cozy`, the reply includes one line to paste into PowerShell that sets the current window to the active scheme (background, foreground and the 16 ANSI colours), and a second line that puts the window back:

```powershell
Write-Host -NoNewline "$([char]27)]111$([char]27)\$([char]27)]110$([char]27)\$([char]27)]104$([char]27)\"
```

The paste line changes only the tab it runs in. Run it in that tab before you start `claude`. Running it as a `!` command inside Claude Code does nothing: the command's output is captured and never reaches the screen.
